1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
SyncCore is an enterprise-grade, pitch-black real-time team collaboration and 
analytics platform. It unifies project management, granular task assignment, 
contextual real-time messaging, and live database aggregation metrics into a single 
high-performance workspace.

--------------------------------------------------------------------------------
2. KEY FEATURES
--------------------------------------------------------------------------------
- Real-Time Team Channels & Direct Messages (Socket.io WebSocket synchronization)
- Kanban Workspaces & Subtask Delegation with multi-member collaboration
- Granular Role-Based Access Control (RBAC): Admin vs Assignee/Collaborator rights
- Base64 Client-Compressed Image Attachments with built-in Lightbox zoom
- Live MongoDB Aggregation Analytics for team throughput, efficiency & workload

--------------------------------------------------------------------------------
3. ADMIN VS USER WORKFLOWS & ACCESS MATRIX
--------------------------------------------------------------------------------

[ ADMIN WORKFLOW ]
1. Create Team Workspace -> Becomes Workspace Owner / Admin
2. Invite Members via @username handles into the workspace
3. Create Projects and Subtasks with single Primary Assignee & Multiple Collaborators
4. Manage workspace member roles (Promote to Admin / Remove Member)
5. Full access to edit/delete any task or status across the workspace

[ REGULAR MEMBER / USER WORKFLOW ]
1. Join Workspace via invitation
2. Participate in #general channel and 1-on-1 Direct Messages (DMs)
3. Update Status of subtasks where user is Primary Assignee or Collaborator
4. View real-time workload and velocity analytics on Analytics Board

+-------------------------------------+------------------+---------------------+
| Action / Resource                   | Admin            | Assignee/Collab     |
+-------------------------------------+------------------+---------------------+
| Create Project / Task               | YES              | NO                  |
| Invite / Remove Workspace Members   | YES              | NO                  |
| Update Assigned Task Status         | YES              | YES (Assigned Only) |
| Update Unassigned Task Status       | YES              | NO (Restricted)     |
| Send Real-Time Chat & Images        | YES              | YES                 |
| View MongoDB Analytics Dashboard    | YES              | YES                 |
+-------------------------------------+------------------+---------------------+
